# annu-comm
Project Description

Annu Comm is a phone gadget business. This website will help customers view available products, see pictures and prices, and find the shop’s contact information and location.

Products

* Phone chargers
* Earpieces
* Power banks
* Phone cases

Main Features

* Product images and prices
* Business contact information
* Shop location
* Responsive design

Technologies

* HTML
* CSS
* JavaScript (planned)

Project Status

Currently under development.
